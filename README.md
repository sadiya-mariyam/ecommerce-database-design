# E-Commerce Database Design

## Overview

This project contains the database design for an e-commerce system.

The database design covers:

- Seller and Inventory Management
- Customer Orders and Order Details
- Payment Management
- Product Reviews and Ratings

## Modules

### 1. Seller & Inventory Management

Manages sellers, products, seller-specific listings, inventory quantities,
availability, stock levels, and reorder alerts.

### 2. Orders & Order Details

Manages customers, orders, order line items, quantities, prices, order
status, and customer order history.

### 3. Payment Management

Manages payment attempts, payment methods, transaction status,
successful payments, failed payments, refunds, and payment reports.

### 4. Reviews & Ratings

Manages customer reviews, product ratings, moderation status, and
aggregate product ratings.

## Database

The designs are written for MySQL / MariaDB.

## Documentation

The `docx` files contain the detailed database design for each module.
